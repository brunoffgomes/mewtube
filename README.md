# MeowTube

A warm home for cat videos. Search by title or channel, filter with chips, and open a video to watch it with Up next and comments.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on [http://localhost:4721](http://localhost:4721).

## Scripts

- `npm run dev` — start the Next.js dev server on port 4721
- `npm run build` — production build
- `npm run start` — serve the production build on port 4721
- `npm run lint` — run ESLint
